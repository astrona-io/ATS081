# Simplified Access to Platform Capabilities

This section covers simplified Access to Platform Capabilities. It develops self-Service Requests, Guardrails And Useful Status through mechanisms, examples, prerequisites and failure reasoning.

Read the module goals, teaching and closing summary in order. YAML checks are indexed separately and appear after designated summaries. Larger domains can include intermediate checkpoints before the final review.

## Learning Outcomes

- Explain self-service as supported independent capability consumption.
- Distinguish guardrails from hidden manual dependencies.
- Reason about request status, permission and exception handling.
