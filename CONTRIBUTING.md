# Contributing

Read CLAUDE.md before editing. Its shared prefix is copied from ATS015, while the custom portion describes ATS081: Certified Cloud Native Platform Engineering Associate (CNPA), IDPs and Developer Experience (8%), part of ATP016.

Preserve IDs, weights and existing track registration. Develop self-contained explanations with mechanisms, examples, prerequisites and failure reasoning. Start each section with an introduction and end each module with its own Summary. Keep technical Markdown draft until review.

The maintainer lifted the reading-only rule on 2026-11-03: labs, playgrounds, capstones and quizzes are in scope. Labs are built untested and checked statically (`astrona validate -c`, `bash -n`, YAML parsing). Do not claim executed results until a lab was run. Quizzes are `quiz.yaml` per section plus `sections/final-domain-quiz.yaml`.

Use primary sources in SOURCES.md and record adaptation paths in AUTHORING.yaml. Run the preparation reading verifier and content-sync parser checks when changing structure. Review Markdown and questions for semantic correctness as well as structure.
